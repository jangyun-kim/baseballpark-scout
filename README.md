# baseballpark-scout

> KBO 직관 예매 준비 대시보드 — 좌석 우선순위 산출 · 서버시각 동기화 · 예매 준비 상태 점검

낮경기 3루가 그늘인지 아닌지 좌석 선택창에서 고민하다 자리를 놓치는 문제를 없애기 위해 만든 도구입니다.
티켓팅의 승부는 클릭 속도가 아니라 **좌석 선택창에서 망설이는 3초**에서 갈립니다.
이 프로젝트는 그 3초를 예매 시작 전에 미리 끝내둡니다.

**현재 상태: 설계 완료 / 기술 검증(스파이크) 진행 중**

---

## 이 프로젝트가 하지 않는 것

본 프로젝트는 다음을 **일절 수행하지 않습니다.**

- 예매 페이지 자동 새로고침
- 예매안내 페이지 자동 통과
- 클린예매(보안문자) 자동 입력
- 좌석 자동 선택 및 자동 결제
- 예매처 서버에 대한 반복 폴링 / 잔여석 스크래핑

2026년 8월 11일 시행된 개정 「공연법」·「국민체육진흥법」은 매크로 사용 여부와 관계없이
정보시스템의 보안조치를 기술적으로 우회하는 부정구매를 금지하고 있으며,
예매 사업자에게도 부정구매 방지를 위한 기술적·관리적 조치 의무를 부과하고 있습니다.

본 도구는 **예매 행위 이전 단계의 의사결정과 내 PC 상태 점검만을 지원**하며,
예매처 서버와의 통신은 서버시각 동기화를 위한 **HEAD 요청 최대 24회(약 3초)** 로 코드에 하드코딩되어 있습니다.

## 주요 기능

### 1. 서버시각 동기화 (`src/core/server_time.py`)

HTTP `Date` 응답 헤더의 **초 경계를 검출**해 밀리초 단위 서버시각을 추정합니다.
`Date` 헤더는 1초 해상도이므로 단순 조회만으로는 ±500ms 오차가 발생하지만,
초가 바뀌는 순간을 포착하면 **±50~100ms** 까지 수렴합니다.

- 오차 신뢰구간(±ms) 실시간 표시
- 티켓링크 `Date` / NTP / OS 시계 **3중 교차검증**
- 개인 반응지연 캘리브레이션 → 클릭 큐를 `T - 본인반응지연` 시점에 발사
- 오디오 큐 (T-10초부터 틱, 3·2·1 음성)
- 리허설 모드

> ⚠️ CDN 엣지 시각과 예매 서버 시각의 차이는 보정 불가능합니다. "오차 0"은 물리적으로 성립하지 않습니다.

### 2. 좌석 우선순위 엔진 (`src/core/seat_score.py`)

날짜 · 시각 · 날씨 · 동반인원 · 응원성향을 반영해 좌석 블록을 채점합니다.

**하드 게이트** (먼저 제외)
- `party_size` — 커플석/테이블석/패밀리석 인원 불일치
- `cheer_mode` — 응원 몰입 / 조용한 관람

**가중 점수축**

| 축 | 내용 |
|---|---|
| `shade` | 태양 방위각과 좌석 향의 차이 |
| `rain` | 강수확률 × 지붕 유무 |
| `allegiance` | 응원팀 응원석 방향 부합도 |
| `sightline` | 그물 · 기둥 · 응원단상 · 중계카메라 · 층수 |
| `immersion` | 홈플레이트 거리와 고도각 |
| `logistics` | 매점 · 화장실 · 출구 동선 |
| `value` | 가격 대비 만족 |

**최종 우선순위**

```
Priority = Satisfaction^α × GrabProbability^β    (α=1.0, β=0.6)
```

β를 낮추면 "어렵더라도 좋은 자리", 높이면 "확실히 잡히는 자리"가 상위로 올라옵니다.

### 3. 그늘 판정 규칙

> **좌석이 바라보는 방향과 태양 방위각의 차이가 90°를 넘으면 그늘.**

관중은 등 뒤 상단 구조물에 가려지므로, 태양이 등 뒤에 있을 때 그늘에 듭니다.

| 구장 | 홈→2루 방위각 | 1루 좌석 향 | 3루 좌석 향 | 낮경기 판정 |
|---|---|---|---|---|
| 대구 삼성 라이온즈 파크 | 67.5° (ENE) | 337.5° | 157.5° | **1루 직사광 / 3루 그늘** |
| 잠실야구장 | 202.5° (SSW) | 112.5° | 292.5° | **1루 그늘 / 3루 직사광** |

두 값 모두 커뮤니티 실측 관측(그늘 시작 열, 시간대별 그늘 진행)과 교차검증했습니다.

### 4. 예매 준비 상태판 (`src/system/readiness.py`)

내 PC 상태만 읽습니다. 예매 사이트를 건드리지 않습니다.

| 항목 | 방법 |
|---|---|
| 한/영 IME 변환모드 | `ImmGetDefaultIMEWnd` + `WM_IME_CONTROL` |
| CapsLock | `GetKeyState(VK_CAPITAL)` |
| 브라우저 줌 배율 | Chrome 확장 `chrome.tabs.getZoom` → 로컬 WebSocket |
| OS 디스플레이 배율 | `GetDpiForWindow` |
| 네트워크 RTT | HEAD 1회 왕복 |
| CPU / 메모리 여유 | `psutil` |
| 전원 계획 | `powercfg` |
| 마우스 예상 이동시간 | 피츠의 법칙 + 실측 보정 |

Chrome 확장은 `"tabs"` 권한만 사용하며 **content script를 페이지에 주입하지 않습니다.**

## 실행

```powershell
git clone https://github.com/<계정>/baseballpark-scout.git
cd baseballpark-scout

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

Copy-Item .env.example .env    # 기상청 API 키 입력
streamlit run src/app.py
```

## 알려진 한계

- KBO는 공식 일정 API를 제공하지 않습니다. 경기 일정은 CSV 수동 입력입니다.
- 그늘 판정은 지붕·상단 스탠드의 3D 그림자를 계산하지 않는 근사 모델입니다.
- 라팍은 2026시즌 기둥 12개가 추가 설치되어 시야 데이터 재실측이 필요합니다.
- 좌석 확보 난이도와 소진 속도는 초기값이 추정치이며, 실사용 로그로 보정해야 합니다.
- 좌석배치도 원본 이미지는 저작권 문제로 리포지토리에 포함하지 않습니다.
