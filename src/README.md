# baseballpark-scout

> KBO 티켓팅 타이밍 도구 — 예매처 서버시각 동기화 · 클릭 큐 · 준비 상태 점검

티켓팅의 승부는 클릭 속도가 아니라 **정각을 얼마나 정확히 아는가**와
**그 순간 내 PC가 준비돼 있는가**에서 갈립니다.

**현재 상태: 기술 검증(스파이크) 5건 전부 통과 / MVP 구현 중**

---

## 이 프로젝트가 하지 않는 것

- 예매 페이지 자동 새로고침
- 예매안내 페이지 자동 통과
- 클린예매(보안문자) 자동 입력
- 좌석 자동 선택 및 자동 결제
- 예매처 서버에 대한 반복 폴링 / 잔여석 스크래핑
- 타 서비스(시야 확인 사이트 등)의 데이터 무단 수집

2026년 8월 11일 시행된 개정 「공연법」·「국민체육진흥법」은 매크로 사용 여부와
관계없이 정보시스템의 보안조치를 기술적으로 우회하는 부정구매를 금지하며,
예매 사업자에게 부정구매 방지를 위한 기술적·관리적 조치 의무를 부과합니다.

본 도구는 **예매 이전 단계의 준비와 내 PC 상태 점검만** 지원합니다.
예매처와의 통신은 서버시각 동기화를 위한 **HEAD 요청 최대 24회(약 3초)** 로
코드에 하드코딩되어 있으며, 설정으로 노출하지 않습니다.

## 핵심 기능

### 1. 서버시각 동기화 (`src/core/server_time.py`)

HTTP `Date` 응답 헤더의 **초 경계를 검출**해 밀리초 단위 서버시각을 추정합니다.
`Date` 헤더는 1초 해상도라 단순 조회로는 ±500ms 오차가 나지만,
초가 바뀌는 순간을 포착하면 **±100ms 이내**로 수렴합니다.

동기화 이후에는 `time.monotonic()` 으로 자체 진행하며 재요청하지 않습니다.

- 오차 신뢰구간(±ms) 상시 표시 — 과신 방지
- NTP 교차검증으로 이상 감지
- **클릭 큐**: 사용자 반응지연만큼 앞당겨 신호를 발사

### 2. 예매 준비 상태판 (`src/system/readiness.py`)

전부 읽기 전용이며 예매 사이트를 건드리지 않습니다. 내 PC 상태만 봅니다.

| 항목 | 구현 |
|---|---|
| 한/영 IME 변환모드 | `ImmGetDefaultIMEWnd` + `WM_IME_CONTROL` |
| CapsLock | `GetKeyState(VK_CAPITAL)` |
| 브라우저 배율 | Chrome 확장 `chrome.tabs.getZoom` → 로컬 WebSocket |
| CPU / 메모리 여유 | `psutil` |
| 전원 계획 · 배터리 | `powercfg`, `psutil` |
| 서버시각 동기 상태 | 위 모듈과 연동 |

Chrome 확장은 `"tabs"` 권한만 사용하며 **content script 를 주입하지 않습니다.**

### 3. 예매 로그 (예정)

시도한 좌석, 성공 여부, 소진까지 걸린 시간을 기록해
블록별 소진 속도를 학습합니다. 쓸수록 우선순위 추천이 정확해집니다.

## 부속물 — 구장 좌석 데이터

`src/data/stadiums.json` 에 라팍·잠실의 좌석 구조, 시야 실측, 응원석 방향,
태양 방위각을 담았습니다. **한 번 만들면 바뀌지 않는 정적 데이터**이므로
프로그램 기능이라기보다 참조용 자료에 가깝습니다.

주요 확인 사항:

| 구장 | 홈 응원석 | 삼성 팬 좌석 | 낮경기 일조 |
|---|---|---|---|
| 대구 라팍 | 3루 (블루존 1~7구역) | 3루 | 15:30 이후 1루 직사광, 3루 그늘 |
| 잠실 | 1루 | 3루 | 4~8월 3루 직사광 고정 |

- 라팍 블루존 실측 결과 **7구역이 시야 최상** (통칭 명당인 2·3·4구역보다 우위)
- 잠실 3루 블루석 114·115는 그물+응원단상 전열 차단 — 배제 권고
- 잠실 412(중계카메라) / 417~422(안전유리) / 421(홈런볼대)는 예매처가
  시야방해석으로 직접 표기

## 실행

```powershell
git clone https://github.com/<계정>/baseballpark-scout.git
cd baseballpark-scout

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

Copy-Item .env.example .env    # 기상청 API 키 입력
streamlit run src/app.py
```

브라우저 배율 표시를 쓰려면 `chrome://extensions` → 개발자 모드 →
압축해제된 확장 프로그램 로드 → `extension/` 폴더를 선택하세요.

## 기술 검증 결과

| # | 항목 | 결과 |
|---|---|---|
| S1 | 티켓링크 서버시각 | ✅ CDN 미경유(Apache 직결), 오차 ±93ms, 5회 요청 |
| S2 | Chrome 한/영 감지 | ✅ Chrome·티켓링크 예매창에서 정상 감지 |
| S3 | 확장 줌 브리지 | ✅ 배율 변경 62~234ms 반영 |
| S4 | 구장 방위각 | ✅ 라팍 약 52°, 그늘 판정 현장 보고와 정합 |
| S5 | 기상청 API | ✅ 라팍·잠실 POP/TMP 정상 수신 |

S5는 공공데이터포털 서비스키의 **이중 인코딩**이 원인으로 403이 발생했습니다.
발급키에 이미 URL 인코딩이 적용돼 있어 `unquote()` 로 되돌린 뒤 넘겨야 합니다.

## 알려진 한계

- Windows 전용 기능이 있습니다 (한/영 감지, 전원 계획). 다른 OS 에서는
  해당 항목이 "조회불가"로 표시되며 나머지는 정상 동작합니다.
- CDN 엣지 시각과 예매 서버 시각의 차이는 보정할 수 없습니다.
  티켓링크는 현재 CDN 을 경유하지 않아 문제되지 않지만 언제든 바뀔 수 있습니다.
- 그늘 판정은 지붕·상단 스탠드의 3D 그림자를 계산하지 않는 근사 모델입니다.
- 구장 방위각은 위성 이미지 역산값으로 ±10° 오차가 있습니다.
  실전 판정이 바뀌지 않는 범위임을 확인했습니다.
- 좌석 확보 난이도는 추정치이며 실사용 로그로 보정이 필요합니다.
- 좌석배치도 원본 이미지는 저작권 문제로 포함하지 않습니다.
